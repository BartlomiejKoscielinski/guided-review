# Process improvements

The feedback loop for how we build Guided Review (not the product). Data: `node tools/metrics/report.mjs` (ledger `.metrics/sessions.jsonl`, from the Claude Code transcripts; `.verify/timings.jsonl` for verify steps). `/retro` reads the numbers, judges the open experiments below, and adds at most three new ones. Every change to the process is an experiment with a metric and a baseline, so it can be kept or reverted on evidence.

## Ideas

Candidate changes to the mechanism that are not experiments yet; every `/retro milestone <Mx>` re-ranks them (quality, then time, then cost) and starts at most two.

- 2026-10-19 · Tests author locks the failure paths of every GitLab write: a retry after a partial failure sends only what the user still sees, a failed sub-request (summary comment) is reported, the outcome survives a restart · F-12.5 severe ×2 + normal ×1 (3 of 20 M5 severe+normal). Re-ranked M6 (first): same class again, F-20.6 normal (job_play reports an error after GitLab accepted the play because the local SQLite write failed); start with E28 or right after it.
- 2026-10-20 · One error-copy table per milestone: the planner writes the approved copy for every GitLab refusal (403, 4xx, unreachable) once, and `prompt.mjs` pastes it into every implementer and reviewer prompt · F-20.2 and F-20.3 normal (raw GitLab message on screen instead of M6 decision 8 copy), 2 of 14 M6 severe+normal.
- 2026-10-20 · Role output fields the conductor relies on are checked by a script, not trusted: `record.mjs` rejects a role answer missing a required field and sends it back once · E26: 5 of 10 implementers skipped `clauses`; prompt rules are followed about half the time.
- 2026-10-16 · A risk checklist per screen for the test author (virtualized rows remount, both layouts and line kinds, restored screen, renamed files): the severe findings of F-11.1, F-11.2 and F-11.3 were all in these classes · P-083, P-084, P-087. Re-ranked M6: M6 did not touch S-03/S-04 (no hits); keep, first when a milestone touches them.
- 2026-10-19 · Mock-real parity: every e2e flow that ends in a real IPC command gets a Rust test of the same state in the same item · F-12.7 severe (drafts-only Publish passed in the mock, failed in the core). Re-ranked M6: no hit in 10 items; drop at the M7 review if still none.
- 2026-10-19 · Accessibility line in the tests role (live region for Claude progress, roles on status text) · F-12.4 normal, F-13.3 normal. Re-ranked M6: nits only (F-20.1 tabpanel, F-20.10 link names); keep low.
- 2026-10-19 · Conductor shell calls: `Bash: python` 7–42× per autopilot session in 6 sessions, `git status`/`git diff` (R2, R10): find what the conductor parses with python and give `backlog.mjs`/`judge.mjs` a subcommand that prints it · report --last 8. Re-ranked M6: time and cost; still needs one interactive look; keep.
- 2026-10-16 · The conductor pastes every role prompt into its own context (316k max in an M6 autopilot session): let the role read its prompt file instead, to keep the conductor small · metrics R4, R11. Re-ranked M6: cost only; keep behind the quality items.
