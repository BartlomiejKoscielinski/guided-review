## Decisions (approved)

1. **MR lists via GraphQL** (new ADR-024, 05 update): REST lists lack +/−, `changes_count`, `head_pipeline` and unresolved counts. One query per tab: `project.mergeRequests(state, reviewerUsername|authorUsername)` with `diffStatsSummary`, `headPipeline.status`, `approvedBy`, `reviewers`, resolvable/resolved discussion counts; replaces the per-MR approvals fallback. Verify every field on the stand-in (17.11.7) by introspection first; a missing field falls back to REST and is recorded in 05.
2. **S-02 in M2**: Preparing state per spec + minimal prepared state (header, **Browse files instead** → S-06 read-only MR browse with Open in Rider). Plan region placeholder; F-06.11 ticks in M3.
3. **Sessions for commit/local** are created now and navigate to stub routes. Current branch → `Local{BranchVsTarget}`; other branch → `Commits{merge-base..branch}`; an unconfigured path is added as a repository, then self-review. "Pick up where you left off" hidden until M3 (justified design-check difference).
4. **Layer rules** (new 05 subsection), first match, case-insensitive: Tests (segment `*Tests*`/`test`) · Platforms (segment `Platforms`) · Build (`.csproj .sln .props .targets Directory.* .gitlab-ci.yml global.json nuget.config`) · Resources (segment `Resources`, `.resx`) · XAML (`.xaml`, `.xaml.cs`) · Core (segment `*.Core`/`Core`) · Infrastructure (segment `*.Infrastructure`/`Infrastructure`) · App (other `.cs`) · Other.
5. **New copy** (into 01/02): "No commit, branch or repository matches “x”." · "x is not the configured GitLab server." · "mobile/x is not one of your repositories. Add it in Settings › GitLab." · "Updated 7 min ago" · "Large: the plan splits it by layer" at ≥ 40 files · note priority: unresolved threads > Large > "You're a reviewer".
6. **Range selection**: Browse files disabled; **Review `<from>..<to>`** handles ranges.
7. **MR URL of another configured repository** switches the active repository; unknown project → error from 5.
