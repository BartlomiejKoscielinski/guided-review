Architektura: aplikacja desktopowa
Tauri 2: interfejs w WebView2, rdzeń w Rust, jedna aplikacja z ikoną w trayu. git, Claude i indeks kodu działają jako procesy potomne, GitLab przez HTTP.
Interfejs
React + TS · WebView2
Własny, wirtualizowany widok diffu tylko do odczytu. Podświetlanie Shiki w Web Workerze. Układy A, B, C na tych samych komponentach.
Rdzeń w Rust
Tauri 2 · tokio
Sesje przeglądu i ich stan. Kolejka zadań dla Claude z limitem równoległości. Pre-fetch następnego kroku. Parsowanie diffu i różnice w obrębie linii. Mapowanie szkiców na pozycje w GitLabie. Tray i sprawdzanie GitLaba w tle.
git CLI + worktree
Fetch refu MR, worktree na head SHA, diff z --find-renames i własnym wykrywaniem przeniesionego kodu, range-diff między wersjami MR. Lokalnie: staging hunków, commit i fixup, push.
claude -p · Claude Code, Twoje logowanie Enterprise
W worktree, tylko odczyt. JSON wg schematu, --resume, model i effort per zadanie. Edycja tylko przy poprawce na Twoim MR, i tylko jednego pliku.
GitLab REST API v4 · on-prem, PAT per osoba
MR, wersje MR, dyskusje i resolve. Approve i publikacja komentarzy osobno. Pipeline dla MR, play, retry i logi jobów.
SQLite · cache i stan sesji
Wyniki Claude kluczowane przez base, head, hash kroku i wersję promptu. Ponowne otwarcie MR jest natychmiastowe.
W repo: .review/
Reguły zespołu i checklisty MAUI. Zmiana reguły tylko przez MR, jak kod.
Indeks kodu · csharp-ls, Roslyn LSP, tree-sitter
Działa na worktree MR: hover, definicja, użycia, także poza MR. Bez buildu tylko indeks symboli.

rider64 --line otwiera plik. Z Ridera wracasz przez guidedreview:// albo External Tools.
